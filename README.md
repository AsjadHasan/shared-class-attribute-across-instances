# shared-class-attribute-across-instances
A Python OOP exercise demonstrating class attributes shared across multiple instances, including how modifying a class attribute updates the default values of all instances that have not overridden it.
<br>
Topics Covered:
<br>

1. Class Attributes
2. Instance Attributes
3. Shared Attributes Across Instances
4. Class-Level Variable Modification
5. Object Instantiation
6. Attribute Access
7. Difference Between Class and Instance Attributes
8. Python OOP Fundamentals
